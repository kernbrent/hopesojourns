Run `build_metro_mexico.py` with the bundled Python runtime (ReportLab required) to regenerate `../Metro-Relief-Mexico-City-Brochure-2027.pdf`.

Panel order, with the text upright: outside 3 / 6 / 1; inside 2 / 4 / 5. Revised October 29, 2026 at Brent's request. The revised former panel 2 is now panel 3. Its participation section uses tighter spacing and slightly smaller type so all content fits comfortably above the footer.

The connected-M logo comes from `MetroRelief/brand/metro-relief-logo.png`. The family photo, Hope Sojourns logo, and original vector QR rectangles were extracted from the existing brochure without changing their content. The QR geometry is retained verbatim.

Vision summary source: https://www.metrorelief.org/vision-25-in-5 (checked October 29, 2026). The goal is to help build or impact 25 communities worldwide in five years using Metro Relief's model through local partnerships, mentoring, and training leaders. The founder's surname is Bonds.
